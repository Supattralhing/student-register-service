# Answer sheets

These are for the teacher. Read each small section of a lesson with the learner
and let them write the code first; use these to check, or to recover a broken
file.

The `.txt` ending keeps Go from building them. Copy the contents into the
matching `.go` file in `server/` if you need to.

| Folder | The code at the end of | Shape |
| --- | --- | --- |
| `lesson-11/` | Lesson 11 | One file. Friends live in `friend_group.friends`, an array. |
| `lesson-13/` | Lesson 13 | One file. Friends live in the `friendship` table, with a date. |
| `lesson-15/` | Lesson 15 | Three files plus tests. Same behaviour as `lesson-13/`, rearranged. |

Reading `lesson-11/main.go.txt` and `lesson-13/main.go.txt` side by side shows
the whole migration: what the new design deleted, and what it made shorter.
